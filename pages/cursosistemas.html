Desenvolvimento de Sistemas

Integre dados e transforme em informações relevantes. Desenvolva sistemas completos (Full Stack) e atenda a uma das maiores demandas do mercado global.

Sobre o Curso

O sistema de informação cria milhares de dados todos os dias. O profissional que integra esses dados e transforma em informações relevantes para empresas está em grande ascensão.

O Técnico em Desenvolvimento de Sistemas surge para suprir essa demanda de mercado, desenvolvendo sistemas completos e com habilidade conversacional em língua inglesa (no modelo bilíngue). O grande crescimento na área exige a capacidade de atuação em nível global.

Aumente suas possibilidades de atuar em grandes organizações multinacionais e esteja apto a ser um profissional altamente qualificado com atuações como assistente de banco de dados e assistente de desenvolvimento full stack.

Grade Curricular

  • Lógica de programação e algoritmos
  • Modelagem de banco de dados
  • Linguagem SQL
  • Introdução a sistemas de informação
  • HTML5, CSS3 e interfaces responsivas
  • Lógica com JavaScript
  • Frameworks front-end modernos (ex: React, Angular)
  • Design de interfaces (UI/UX)
  • Linguagem de servidor (ex: Java, Python, C#)
  • Criação de APIs RESTful
  • Arquitetura de microsserviços
  • Projeto integrador full-stack
