4. Tipografia

Atual: apenas Arial, Helvetica, sans-serif, sem escala de tamanhos definida — tamanhos de fonte não aparecem nos CSS (só herda o padrão do navegador). Não há hierarquia clara entre h2/h3/parágrafo além do text-align: center.

Sugestão de escala tipográfica para o redesign

H1 — Título de página (28px / bold)
H2 — Título de seção (22px / bold)
H3 — Subtítulo (17px / bold)
Parágrafo / corpo de texto (14px / regular, altura de linha 1.5)
Legenda / texto auxiliar (12px)

Família sugerida: manter Arial/Helvetica/sans-serif (ou trocar por algo como Inter/Roboto via Google Fonts, se o professor permitir dependências externas) — mas definindo os tamanhos acima em vez de deixar no padrão do navegador.

6. Problemas encontrados no CSS atual (para não repetir)

  • bug menu.css tem propriedades inválidas/erros de digitação: smargin, sfont-family, stransition, e em pag cursos style.css há wdith sem valor — CSS quebrado que o navegador ignora silenciosamente.
  • bug cadastro.css está vazio — a página de cadastro provavelmente depende só de estilo inline ou de outro arquivo.
  • layout Larguras fixas em pixels (width:500px) em vários lugares (parágrafos, tabelas) em vez de unidades relativas — quebra em telas menores mesmo com media query.
  • layout Página de cursos usa <table> para organizar cards de curso — tabelas devem ser usadas para dados tabulares, não para layout de cards.
  • nome de arquivo "pag cursos style.css" tem espaço no nome, o que obriga a escrever a URL com %20 ou aspas — evite espaços em nomes de arquivo.
  • acessibilidade Menu mobile usa o "checkbox hack" com visibility em vez de classe JS — funciona, mas é frágil e sem estados aria-*.
  • cor Poucas cores nomeadas — darkblue, blue usados como palavras-chave CSS em vez de valores hex consistentes com o resto da paleta.

8. Componentes a redesenhar

  • Menu principal — trocar o checkbox hack por classe JS simples; usar cor primária 500 no fundo e garantir contraste do texto.
  • Cards de curso — substituir a <table> por grid de cards com imagem, título e botão "saiba mais".
  • Formulários (cadastro/login/senha) — precisam de estilo próprio (hoje cadastro.css está vazio); usar cores semânticas para erro/sucesso e campos com foco visível.
  • Rodapé — manter ícones de redes sociais, mas padronizar tamanho (hoje footer img usa width:5%, que fica minúsculo em telas largas).
